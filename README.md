# Yandex Music Export

Инструмент для экспорта музыкальной библиотеки из Яндекс.Музыки в JSON или CSV.

## 🚀 Быстрый старт

### Windows

Запустите `start.bat` — скрипт автоматически создаст виртуальное окружение, установит зависимости и запустит меню:

```bash
start.bat
```

### Linux/macOS

```bash
# Установка зависимостей
pip install -r requirements.txt

# Запуск
python export_yandex.py
```

## 📤 Возможности

- ✅ Экспорт лайкнутых треков («Мне нравится»)
- ✅ Экспорт пользовательских плейлистов
- ✅ Разделение треков на доступные/недоступные/UGC
- ✅ Форматы: JSON (рекомендуется) и CSV
- ✅ Интерактивное CLI-меню
- ✅ Сохранение токена в конфиге
- ✅ Логирование в файл

## 📖 Использование

### Главное меню

```
[1] Экспорт "Мне нравится" (треки)
[2] Экспорт плейлистов
[3] Настройки / Информация
[0] Выход
```

### Экспорт лайкнутых треков

Доступны три варианта:
- **Все треки** — доступные + UGC + удалённые
- **Только доступные** — треки из каталога Яндекс.Музыки
- **Только недоступные** — UGC-треки и удалённые правообладателями

### Экспорт плейлистов

- Экспорт всех плейлистов
- Выбор конкретных плейлистов по номерам

## 📝 Форматы экспорта

### JSON (рекомендуется)

```json
[
  {
    "type": "playlist",
    "title": "Мне нравится",
    "kind": "likes",
    "track_count": 150,
    "tracks": [
      {
        "position": 1,
        "type": "track",
        "id": "12345678",
        "title": "Название трека",
        "artists": "Исполнитель 1, Исполнитель 2",
        "album": "Название альбома",
        "year": 2023,
        "duration_ms": 180000,
        "isrc": "USRC12345678",
        "source": "UGC",
        "availability_reason": "deleted"
      }
    ]
  }
]
```

### CSV

Табличный формат для импорта в Excel/Google Таблицы.

## ⚙️ Конфигурация

Файл `config.json` создаётся автоматически при первом запуске:

```json
{
    "yandex_token": "ваш_токен",
    "export": {
        "default_format": "json",
        "default_filename": "yandex_export",
        "default_type": "all"
    },
    "display": {
        "show_track_count_preview": true,
        "tracks_per_page": 20
    }
}
```

> ⚠️ **Важно:** `config.json` добавлен в `.gitignore` — ваш токен не попадёт в репозиторий!

## 🔐 Как получить токен Яндекс.Музыки

### Способ 1: DevTools браузера

1. Откройте https://music.yandex.ru
2. Нажмите **F12** (DevTools)
3. Перейдите на вкладку **Network** (Сеть)
4. Обновите страницу (F5)
5. Найдите запрос к API
6. В заголовках найдите `Authorization: OAuth <token>`
7. Скопируйте токен (без `OAuth `)

### Способ 2: OAuth Яндекс

1. Перейдите по ссылке:  
   `https://oauth.yandex.ru/authorize?response_type=token&client_id=23cabbbdc6cd418abb4b39c32c41195d`
2. Авторизуйтесь
3. Скопируйте `access_token` из URL редиректа (значение до `&`)
