# Yandex Music Export

Инструмент для экспорта музыкальной библиотеки из Яндекс.Музыки в JSON или CSV.

## 🚀 Быстрый старт

### Windows (рекомендуется)

**Автоматический запуск:**

Запустите `start.bat` — скрипт автоматически создаст виртуальное окружение, установит зависимости и покажет меню:

```bash
start.bat
```

**Меню:**
```
[1] Экспорт из Яндекс.Музыки
[2] Конвертация JSON → TXT
[3] Импорт в Spotify
[0] Выход
```

---

### Ручная установка (Windows)

Если вы хотите настроить окружение вручную:

**1. Создание виртуального окружения:**
```bash
python -m venv venv
venv\Scripts\activate
```

**2. Установка зависимостей:**
```bash
pip install --upgrade pip
pip install -r requirements.txt
```

**3. Запуск:**
```bash
# Экспорт из Яндекс.Музыки
python export_yandex.py

# Конвертация JSON → TXT
python convert_to_txt.py

# Импорт в Spotify
python import_to_spotify.py
```

---

### Зависимости

| Библиотека | Назначение |
|------------|------------|
| `yandex-music>=2.0.0` | Клиент для работы с API Яндекс.Музыки |
| `requests>=2.28.0` | HTTP-запросы к API |
| `spotipy>=2.23.0` | Клиент Spotify (для импорта) |

Все зависимости указаны в файле `requirements.txt`.

## 📖 Использование

### Главное меню

```
[1] Экспорт "Мне нравится" (треки)
[2] Экспорт плейлистов
[3] Настройки / Информация
[0] Выход
```

При выборе экспорта программа экспортирует данные в JSON с автоматическим именем файла.

### Меню плейлистов

```
[1] Экспортировать все плейлисты
[2] Выбрать плейлисты для экспорта
[3] Показать список плейлистов
[0] Назад
```

## 📝 Формат экспорта

Весь экспорт выполняется в формате JSON.

### Структура JSON

```json
[
  {
    "type": "playlist",
    "title": "Мне нравится",
    "kind": "likes",
    "track_count": 150,
    "tracks": [
      {
        "position": 1,
        "type": "track",
        "id": "12345678",
        "title": "Название трека",
        "artists": "Исполнитель 1, Исполнитель 2",
        "album": "Название альбома",
        "year": 2023,
        "duration_ms": 180000,
        "isrc": "USRC12345678",
        "source": "UGC",
        "availability_reason": "deleted"
      }
    ]
  }
]
```

## 📂 Экспортированные файлы

Файлы сохраняются в папку `exports/{login}/`:

```
exports/{login}/
├── json/
│   ├── likes_tracks.json          # Лайкнутые треки
│   └── {название}_playlists.json  # Плейлисты
└── txt/
    ├── likes_tracks.txt           # Лайкнутые треки (формат: Исполнитель - Название)
    └── {название}_playlists.txt   # Плейлисты
```

> ⚠️ **Важно:** Названия файлов автоматически очищаются от запрещённых символов (`<>:"/\|?*`).

### Конвертация в TXT

Для конвертации JSON файлов в TXT используйте:

```bash
python convert_to_txt.py
```

Или выберите пункт `[2] Конвертация JSON → TXT` в меню `start.bat`.

### Импорт в Spotify

Для импорта экспортированных треков в Spotify:

```bash
python import_to_spotify.py
```

Или выберите пункт `[3] Import to Spotify` в меню `start.bat`.

**Процесс импорта:**
1. Введите Client ID и Client Secret от приложения Spotify
2. Выберите тип импорта:
   - «Мне нравится» — импорт лайкнутых треков
   - Плейлист — импорт конкретного плейлиста
   - JSON файл — импорт из произвольного файла
3. Дождитесь завершения импорта

**Результат:**
- Создаётся плейлист в Spotify с найденными треками
- Файл `*_not_found.json` со списком ненайденных треков

## ⚙️ Конфигурация

Файл `config.json` создаётся автоматически при первом запуске:

```json
{
    "yandex_token": "ваш_токен",
    "export": {}
}
```

> ⚠️ **Важно:** `config.json` добавлен в `.gitignore` — ваш токен не попадёт в репозиторий!

## 🔐 Как получить токен Яндекс.Музыки

### Способ 1: DevTools браузера

1. Откройте https://music.yandex.ru
2. Нажмите **F12** (DevTools)
3. Перейдите на вкладку **Network** (Сеть)
4. Обновите страницу (F5)
5. Найдите запрос к API
6. В заголовках найдите `Authorization: OAuth <token>`
7. Скопируйте токен (без `OAuth `)

### Способ 2: OAuth Яндекс

1. Перейдите по ссылке:  
   `https://oauth.yandex.ru/authorize?response_type=token&client_id=23cabbbdc6cd418abb4b39c32c41195d`
2. Авторизуйтесь
3. Скопируйте `access_token` из URL редиректа (значение до `&`)
